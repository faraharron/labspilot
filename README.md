# LabsPilot

Dashboard de gestion et diagnostic des labs numériques — Maroc.

## Déploiement Vercel

1. Allez sur https://vercel.com et connectez-vous avec GitHub
2. Cliquez "Add New Project"
3. Importez le repo `labspilot`
4. Cliquez "Deploy" — c'est tout

## Stack

- React + Vite
- Supabase (base de données)
- Recharts (graphiques)
- SheetJS (import Excel)
